From edit to live.

  1. Open the editor and choose a content section.
  2. Edit or add an item. Upload images through the image field. Keep listening and ticket links complete, starting with https://.
  3. Save. Saving commits your changes and starts an automatic website rebuild.
  4. Check Publish Status. A successful “Build and publish” run means the new version has deployed. Publishing usually takes a few minutes.
  5. Review the live site on desktop or phone. If validation fails, the last successful version stays live; correct the field named in the build log and save again.
